连接与使用说明
电脑双击“启动GitHub实验版.cmd”，验证专用私有仓库并允许本次执行。粘贴配对资料后，首次连接还需电脑确认。等待回应可能需要十几秒，避免重复点击。
电脑须保持开机且服务窗口打开。输入数据在运行前一次性提交；当前版本支持文字程序，暂不支持运行中交互输入和图形窗口。
GitHub 保存任务与结果的密文及访问记录。配对资料含访问令牌，请勿分享。电脑编译和运行启用 Windows LPAC 文件与网络隔离；保存文件由电脑端受控完成。隔离不能保护被替换网页中输入的内容。
添加到 iPad 主屏幕 ↗
在 Safari 中轻点“分享”（方框向上箭头），找到“添加到主屏幕”；若有“作为网页 App 打开”，请开启，再点“添加”。以后轻点主屏幕上的“远程连接”即可打开。
第一次使用主屏幕 App 可能需要重新配对。若提示已绑定另一台设备，请在电脑管理页撤销旧浏览器授权，再连接此 App。旧网页里的练习请先下载备份，再在这里导入。
编译、运行和保存到电脑仍需联网，且电脑保持唤醒、远程连接程序正在运行。关闭 App 后再次打开，可能需要重新连接。
